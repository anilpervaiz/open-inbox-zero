# Third-party licenses

The repository's own code is available under the [MIT License](../LICENSE). Dependencies retain their own licenses; the MIT license does not replace them. `pnpm licenses list --prod --json` reports the licenses of installed production dependencies for the current platform.

A macOS x64 check on 2026-11-13 reported licenses including MIT, ISC, BSD, Apache-2.0, MPL-2.0, CC-BY-4.0, and LGPL-3.0-or-later. In particular, the platform-specific `@img/sharp-libvips-darwin-x64` package reports LGPL-3.0-or-later, `lightningcss` reports MPL-2.0, and `caniuse-lite` reports CC-BY-4.0. Other operating systems can install different optional packages, so inspect the licenses and notices in the actual distribution. This inventory is informational, not a complete legal review.
